## Исправления

Добавлена проверка положительного числового ID (VK/Facebook), исключены bool/None.
VK count должен быть неотрицательным int, оставаться неизменным между страницами;
число полученных записей не может превышать count. Facebook отслеживает ID между
страницами и завершает snapshot ошибкой при повторе. API-ошибки не содержат токенов.
Atomic sync по-прежнему пишет CSV только после полного получения данных;
регрессионный тест подтверждает сохранение старого файла при невалидном count.

## Ограничения

Неизменный count и уникальные ID не доказывают консистентность снимка во времени:
соцграф может изменяться во время чтения. При ошибке нужно повторить импорт.

изолированных вершин в пустом CSV и ограничения приватности остаются в README.
