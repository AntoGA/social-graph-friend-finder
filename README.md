# Social Graph Friend Finder

Прототип рекомендаций друзей по неориентированному графу. Python 3.10+, стандартная библиотека.

## Запуск

```bash
python friend_graph.py example_edges.csv alice --limit 5 --stats
python friend_graph.py example_edges.csv alice --metric adamic-adar --json
python -m unittest discover -v
```

Для искусственного примера порядок: george, diana, elena.
Метрики: `mutual` (общие соседи), `jaccard` (пересечение / объединение соседей),
`adamic-adar` (сумма 1/log степени общего соседа), `combined` (3*mutual + 2*jaccard + adamic-adar).
Комбинированная оценка — эвристика, не вероятность дружбы и не проверенная модель совместимости.
Кандидаты — только друзья друзей. При одном звездообразном снимке рекомендаций владельцу нет.

## API: экспериментальный импорт

Токены задаются через переменные окружения локально. Не присылайте их в чат и не коммитьте.
OAuth-сервер не реализован: получение токена через официальную авторизацию остаётся за оператором.
Версии API и разрешения нужно сверить с настройками собственного приложения. Живые API не входят в CI.

```bash
python social_sync.py --provider vk --token-env VK_ACCESS_TOKEN --output social_edges.csv
python social_sync.py --provider facebook --token-env FACEBOOK_ACCESS_TOKEN --facebook-version "$FACEBOOK_API_VERSION" --output social_edges.csv --append
python friend_graph.py social_edges.csv vk:123456 --json
```

VK адаптер запрашивает users.get и friends.get, Facebook — /me и /me/friends.
Код обрабатывает только реально возвращённые разрешённые данные, а не обещает полный социальный граф.
Facebook использует фиксированный адрес с курсором: полученный paging.next не открывается.
Перенаправления HTTP запрещены; тела ошибок API не выводятся. Повторы после лимитов API пока не реализованы.

**LinkedIn не реализован:** оставлен явно отключённый адаптер, который завершает импорт ошибкой.
Для реализации нужен одобренный API-продукт, документация схемы и согласование пространства идентификаторов.
Не выдавайте этот прототип за работающую интеграцию LinkedIn.

## Снимки и идентичности

По умолчанию импорт заменяет весь выходной CSV. `--append` сохраняет снимки других владельцев,
но заменяет снимок текущего владельца, включая удаление его устаревших связей.
Данные API собираются до записи; CSV заменяется атомарно. Одновременные процессы записи не поддерживаются.
Формат импорта: source,target,provider,owner_id. Обычный графовый CSV требует только source,target.
Пустой снимок не хранит изолированную вершину: для неё CLI сообщит об отсутствующем пользователе.

`--identity-map example_identities.csv` объединяет явно подтверждённые аккаунты в `person:alice`.
Пример содержит вымышленные ID. Не объединяйте аккаунты по совпадению имени.
После изменения identity map пересоберите все снимки, иначе старые строки сохранят прежние ID.
Facebook ID должны происходить из одного приложения; несколько приложений требуют отдельных пространств ID.

## Ограничения безопасности

Это локальный прототип, не production-сервис. Нет авторизации зрителей, фильтров блокировок,
политик видимости связей, шифрованного хранилища и автоматического удаления всех данных участника.
Не публикуйте реальные графы и не предоставляйте рекомендации другим пользователям без этих механизмов.
В публичный репозиторий включены только код и синтетические примеры.
